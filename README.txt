23.6 Практика модели

Задачи

1. Создайте новое приложение library.
2. Добавьте приложение library в файл settings.py.
3. Создайте модели Author и Book в файле library/models.py.

Модель Author

• first_name — имя автора. Строка максимальной длиной 150 символов.
• last_name — фамилия автора. Строка максимальной длиной 150 символов.
• birth_date — дата рождения автора. Поле для хранения даты.

Модель Book

• title — название книги. Строка максимальной длиной 200 символов.
• publication_date — дата публикации книги. Поле для хранения даты.
• author — внешний ключ, связывающий книгу с автором. Указывает на модель
  Author и использует каскадное удаление on_delete=models.CASCADE.
